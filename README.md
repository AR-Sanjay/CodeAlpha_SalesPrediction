# Sales Prediction Using Python

A machine learning project developed as part of the **CodeAlpha Internship**, focused on predicting product sales using advertising expenditure across different marketing channels.

## Project Overview

This project explores the relationship between advertising expenditure and product sales using Python and machine learning.

It uses advertising data from three marketing channels:

- TV
- Radio
- Newspaper

The objective is to develop regression models that estimate sales based on advertising investments and provide insights that can support marketing decisions.

## Objectives

- Understand and explore the advertising dataset.
- Perform data cleaning and preprocessing.
- Analyze relationships between advertising channels and sales.
- Identify relevant features for prediction.
- Train and compare multiple regression models.
- Evaluate model performance.
- Simulate advertising budget changes and analyze predicted sales.
- Generate actionable marketing insights.

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## Machine Learning Models

The project explores multiple regression algorithms, including:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Polynomial Regression
- Random Forest Regressor
- Gradient Boosting Regressor

The final model is selected based on model evaluation and cross-validation results.

## Evaluation Metrics

The models are evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
